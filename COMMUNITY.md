## Suggested Discussions categories
- **Q&A**: reproducible questions about JavaScript, GitHub API and static web apps.
- **Ideas**: practical proposals with a user need and constraints.
- **Show and tell**: verified demos and technical write-ups.

## Genuine recognition
GitHub Achievements are granted by GitHub based on qualifying activity.
- Galaxy Brain depends on helpful answers accepted in Discussions.
- Pair Extraordinaire depends on authentic co-authored commits within qualifying merged PRs.

Never post fictitious answers, self-award acceptance, or add fake co-authors to earn badges.

## Français
L'objectif est de produire des améliorations utiles, des réponses techniques exactes et de vraies collaborations. Les badges sont secondaires et leur attribution dépend de GitHub.
