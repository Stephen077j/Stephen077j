# Contributing / Contribuer

Thanks for considering a contribution to the public demos maintained by Joel Stephen.

## Start with an issue
- Review existing issues and describe the problem or proposed improvement.
- For a code change, open a focused pull request against `main`.
- Explain the change, testing and known limitations.
- Keep each PR scoped to one useful improvement.
- Never include credentials, personal data or customer source code.

## Local checks
Install Node.js 22 or later, then run:

```bash
node --test tests/static-apps.test.cjs
```

Test relevant behavior in a real browser as well. Static checks alone do not prove the UI works.

## Collaboration and credit
Reviewers should verify the change before merging. Use GitHub's `Co-authored-by:` trailer only for people who actually contributed to the commit and have agreed to the attribution. We welcome constructive code reviews and accurate technical explanations.

## Français
Ouvre une issue pour proposer une amélioration, puis une PR ciblée vers `main`. Décris les tests réalisés, ne publie aucune donnée sensible et mentionne uniquement de vrais coauteurs.
