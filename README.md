## ATSIC — Solutions pour vos besoins / Solutions for your business

### Français

Je développe des outils web et mobiles et des bases réutilisables pour organiser les opérations : stock, devis, rendez-vous, interventions et inventaire. Mon travail avec ATSIC relie l’analyse du besoin, le développement logiciel et les vérifications techniques.

| Besoin client | Exemple à présenter | Technologies |
|---|---|---|
| Boutique ou atelier | Stock, mouvements, export et import CSV avec aperçu | Node.js · SQLite |
| Consultant ou prestataire | Devis, remise avant taxe, impression et fichiers JSON | React · TypeScript |
| Salon ou équipe de services | Agenda par collaborateur et contrôle des conflits | Vue · JavaScript |

**Ma méthode :** comprendre le besoin, montrer un exemple avec des données fictives, adapter les règles puis vérifier les parcours. Ces exemples sont des bases locales à personnaliser ; les dépôts sources sont privés. Démonstration accompagnée disponible sur demande.

### English

I develop web and mobile tools and reusable business components for inventory, quotations, appointments and service operations. Through ATSIC, I connect requirements analysis, implementation and technical verification.

**Selected examples:** inventory with CSV preview/import; quotations with discounts, tax and JSON backup; staff appointments with conflict detection. These are local starter projects to adapt to each client. Source repositories remain private; guided demonstrations are available on request.

**Working approach:** understand your workflow, demonstrate with sample data, customize the rules and verify the result. Shared deployments need appropriate access control, backups and hosting.
