# Pygame Math Sprint

A small, independently runnable **Pygame / Python** portfolio example by Joel Stephen. Uses sample data and no production credentials.

## Start

```bash
cd projects/pygame-math/
python -m venv .venv
# Activate .venv then:
pip install -r requirements.txt
python main.py
```

## Tests

Run `python -m unittest discover -s tests -v` with dependencies installed.

## Scope and limitations

This is an educational demonstration, not a production system. The app runs a local keyboard-controlled math game. No authentication, persistent multiuser storage, or sensitive customer records.

## Français
