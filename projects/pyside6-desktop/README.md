# PySide6 Focus Timer

A small, independently runnable **PySide6 / Python** portfolio example by Joel Stephen. Uses sample data and no production credentials.

## Start

```bash
cd projects/pyside6-desktop/
python -m venv .venv
# Activate .venv then:
pip install -r requirements.txt
python main.py
```

## Tests

Run `python -m unittest discover -s tests -v` with dependencies installed.

## Scope and limitations

This is an educational demonstration, not a production system. The app provides a local focus countdown. No authentication, persistent multiuser storage, or sensitive customer records.
