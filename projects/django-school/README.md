# Django School Directory

A small, independently runnable **Django / Python** portfolio example by Joel Stephen. Uses sample data and no production credentials.

## Start

```bash
cd projects/django-school/
python -m venv .venv
# Activate .venv then:
pip install -r requirements.txt
python main.py runserver 127.0.0.1:8000
```

## Tests

Run `python -m unittest discover -s tests -v` with dependencies installed.

## Scope and limitations

This is an educational demonstration, not a production system. The app shows sample students in memory. No authentication, persistent multiuser storage, or sensitive customer records.

## Français

Projet de démonstration Python avec **Django**, documentation et tests. Les données sont fictives et le logiciel n'est pas prêt à être utilisé en production.
