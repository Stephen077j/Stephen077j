# Streamlit Sales Dashboard

A small, independently runnable **Streamlit / Python** portfolio example by Joel Stephen. Uses sample data and no production credentials.

## Start

```bash
cd projects/streamlit-dashboard/
python -m venv .venv
# Activate .venv then:
pip install -r requirements.txt
streamlit run main.py
```

## Tests

Run `python -m unittest discover -s tests -v` with dependencies installed.

## Scope and limitations

This is an educational demonstration, not a production system. The app analyzes small CSV samples. No authentication, persistent multiuser storage, or sensitive customer records.
