**FR** : Bibliothèque de découverte de 200 plateformes classées en 20 domaines. Chaque lien renvoie vers la ressource originale. **EN**: Curated directory of 200 resources across 20 topics, with original links and practical uses.

## Utilisation / How to use

- Parcourir les domaines ci-dessous ou utiliser la recherche GitHub dans ce fichier. / Browse topics or use GitHub's file search.
- Ouvrir la plateforme, examiner sa documentation et ses conditions. / Open the site and review its documentation and terms.
- Pour les données, vérifier leur licence et leur date; pour les logiciels, vérifier la licence du projet précis. / Check dataset licenses and freshness; check each software project's license.
- **Les 200 URL proviennent d'une sélection documentaire, et non d'un contrôle HTTP automatisé de chaque lien.** / These URLs have not each undergone automated live checking.
